**Pneumonia Detection using Deep Learning**
A deep learning application that detects pneumonia from chest X-ray images. The application provides an easy-to-use web interface built with Streamlit.

**Technologies Used**
- Python
- PyTorch
- TorchVision
- Streamlit
- PIL (Python Imaging Library)

**Features**
- Upload chest X-ray images
- Detect pneumonia using a trained deep learning model
- Simple and interactive Streamlit interface

**How to Run**
1. Install the required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
